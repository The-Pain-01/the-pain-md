FREQUENTLY ASKED QUESTIONS

How do I connect my WhatsApp?

Open the Session page, choose QR Code or Pairing Code and follow the instructions. Actual connection requires the backend.

Do I need to create an account?

No website account or password is planned for accessing the platform.

Will my session be saved permanently?

The planned system uses temporary sessions. Definitively ended sessions will have their temporary authentication data deleted by the backend.

Why is my QR Code not appearing?

The frontend is currently a visual interface. QR generation requires the backend service.

Can I use the website on my phone?

Yes. The interface is responsive and adapts to mobile screens.
